Seraphic Blue Updater v1.1.0

Extract the whole ZIP into its own folder. Close the game before updating. Keep payload/ and launchers/ together.

WindowsLinux / DeckWhat stays safeSource

Windows

  1. Double-click SeraphicBlue-Update.exe.
  2. Click Choose and select the current game folder.
  3. Click Update to latest for a manual update. Or click Enable startup checks to check when opening PLAY.cmd.
  4. To stop checks, select the same folder and click Disable startup checks. This restores the original launcher byte-exact.

The startup switch works without a newer release or network connection. Windows PowerShell and .NET Framework are used; no dependencies are installed.

Linux / Steam Deck desktop

  1. Open Startup-settings.desktop from this extracted folder. Your desktop may ask you to trust/run it.
  2. Select the game folder and choose Enable startup checks.
  3. Open that game’s play-linux.sh. A newer matching stable release offers Install update or Play current.
  4. To disable checks, open Startup-settings.desktop again, select the same folder and choose Disable startup checks.

Python 3 and an existing kdialog or zenity are required for graphical setup and prompts. No dependencies are installed. Missing desktop tools are a manual limitation; startup checks quietly continue the current game if tools are missing.

There is no separate Linux Update now button. For one check, enable checks, launch play-linux.sh, then disable them afterward.

What stays safe

  • Updates are optional. Only a newer stable release for the same edition can prompt. Offline/error startup checks continue the current game.
  • A new neighboring version folder receives verified saves/settings and managed Auto sidecars. The old game and a verified backup are retained. Accepted startup updates keep checks enabled in the new copy.
  • Free space is checked before download and again before backup/extraction. ZIP paths, hashes, manifest and personal-data copies are checked. Partial downloads/backups may remain after an error; use the old game.
  • Direct Player.exe / Player shortcuts bypass checks. Steam shortcuts are not changed: point them to the launcher in the version folder you want to play.

No Proton launch options are added. Physical Steam Deck / Proton behavior has not been verified. Native Linux updater logic and dialog commands were checked with disposable fixtures and stubs.

Matching full-game releases are supported. Custom launchers and linked folders require manual handling.

Included source and license
