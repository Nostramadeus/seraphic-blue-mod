Windows — download and play

1. Download the complete English game.

2. Right-click the ZIP → Extract All. Open the extracted SeraphicBlue folder.

3. Double-click PLAY.cmd. Keep the extracted files together.

Player.exe is the game-running program. Its DLL helper files are already included. PLAY.cmd selects this game, puts new saves in saves, and stores Player settings in config. There are no bundled personal saves.

Updating an existing installation

Close the game. Download the new full game ZIP, extract it, and copy the saves folder from your old game folder into the new one. Saves from any earlier test release, the 2016 English patch or the Japanese original load as they are. Details: Keep your saves.

Controls

Arrows move/select. Enter confirms. Escape or right-click goes back. Shift opens secondary actions where shown. Hover highlights; left-click chooses. Keyboard/gamepad navigation keeps control until the pointer moves again. Hover alone never confirms a choice. Mouse wheel changes battle ability/item pages. Page Up/Down changes character tabs.
