Windows — download and play

1. Download the complete English game.

2. Right-click the ZIP → Extract All. Open the extracted SeraphicBlue folder.

3. Double-click PLAY.cmd. Keep the extracted files together.

Player.exe is the game-running program. Its DLL helper files are already included. PLAY.cmd selects this game, puts new saves in saves, and stores Player settings in config. There are no bundled personal saves.

Updating an existing installation

Close the game and back up your actual saves. Extract the smaller Windows Player update separately. Copy only its Player.exe and all DLLs into your existing Player.exe folder; leave game data, saves and EasyRPG.ini alone. Existing custom launch arguments stay unchanged.

Controls

Arrows move/select. Enter confirms. Escape or right-click goes back. Shift opens secondary actions where shown. Hover highlights; left-click chooses. Mouse wheel changes battle ability/item pages. Page Up/Down changes character tabs.
