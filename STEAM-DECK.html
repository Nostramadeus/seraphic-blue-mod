Native Linux

1. Switch to Desktop Mode. Download the complete English game and extract it.

2. Open a terminal in SeraphicBlue (or SeraphicBlue-Altered for the Altered ZIP). Run sh play-linux.sh.

3. To launch through Steam, make play-linux.sh and native-linux/Player executable: chmod +x play-linux.sh native-linux/Player.

4. In Steam choose Games → Add a Non-Steam Game → Browse, show all files, and select play-linux.sh. Set Start In to the game folder. Leave forced Proton compatibility off for this native shortcut.

Keep the extracted files together. Native MIDI uses an available soundfont or the included FM synthesizer; the FM instruments may sound different. Linux requirements and test limits.

Windows Player through Proton

1. Add Player.exe from the same game folder as a Non-Steam Game.

2. Open Properties → Compatibility, enable the forced compatibility tool, and select Proton Experimental.

3. In Shortcut, set Start In to the game folder and Launch Options to:

--project-path . --save-path saves --config-path config --encoding 932 --window

v0.3.3 includes AryaNetwork's PortAudio library fix for the title-screen MIDI crash (issue #1). Windows regression tests passed; we did not run the patched build on physical Deck hardware or Proton.

Updating

Close the game. Back up saves and config. Extract the new ZIP into a new folder and copy those folders from the old installation. Point the Steam shortcut at the new launcher or Player.exe. Keep DC and Altered saves on their matching builds. Keep your saves.

The separate stock Flatpak package contains older test.1 game data and does not supply the current custom Player. Quick start.
