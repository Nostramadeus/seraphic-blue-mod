Release history

v0.3.8 — saved commands and English corrections

saved manual encounter commands in English DC/Altered with explicit R or optional Auto-button start and stop on Windows/native Linux; the idle button defaults Off under F1 > Engine; Stop remains visible during replay; four approved English wording corrections (three matching Altered passages), and one directly translated DC picture card. Existing saves, battle rules and the separate experimental UI are unchanged.

v0.3.7 — picture text and optional song titles

English DC received 83 additional clearer-font cards; Altered received the 75 matching cards. Eight were widened by 1–20 pixels, with complete wording and original heights retained. One source card remained unresolved at that release; v0.3.8 translates it directly in DC. Eight Altered absences/revisions remained untouched.

The optional F1 → Engine → Song title banner starts Off. It shows the music filename after a track change, uses multiple pages for long names, and pauses while dialogue, menus, battle or transitions hide it. Fast-forward does not shorten its four-second display. It is an engine preference, separate from game saves. Full v0.3.7 entry.

v0.3.6 — mouse interaction, comparison and healing

The following features shipped in v0.3.6. An earlier README placed them under v0.3.7; the release notes record their correct version.

  • Mouse selection follows visible character artwork, native counter interaction and a unique adjacent exit. Arrival handling retains touch transfers during a pure speed adjustment.
  • English shops add Tab Compare for weapons and frames, using native calculations without purchases or equipment changes.
  • Altered: Shift dash preserves mouse movement; MOD hover updates its hint; HP Supplement controls appear with free healing Off; new Extra Content HP Auto Fill starts Off; manual FREE rewards stay ordinary.
  • English: 101 approved font cards per edition use a consistent face; 108 title calls keep their complete names inside the screen; one minor Counter Attack wording correction. 84 mixed-layout cards remain unchanged.

  • Restores missing Map0022 (Turku Inn upstairs) and Map0088. Existing saves work; Player, Linux runtime and the DC builds are unchanged. This urgent map-only hotfix received file-integrity checks, without a new gameplay test.

Archived update procedures

For archived test releases only. For a current installation, use the four-step full-game update. These old patch links and file lists are retained for reference.

Test-release patch ZIPs — original sequence
  1. Close the game. Keep a backup of your actual save folder.
  2. On test.6 or older, first apply the test.7 image update (extract beside RPG_RT.ldb, replace the Picture files).
  3. On test.7 or older, download the test.8 update. Extract it into your game folder, beside RPG_RT.ldb, and allow replacement of Player.exe, RPG_RT.ldb, Map0003.lmu and one Picture file. If your Player.exe lives in another folder (older patch installs), copy the new Player.exe there instead.
  4. On test.8 or older, download the test.9 picture update. Extract it into the same folder, beside RPG_RT.ldb, and allow replacement of the 55 Picture files.
  5. On test.9 or older, download the test.10 update. Extract it into the same folder, beside RPG_RT.ldb, and allow replacement of Map0507.lmu.

Later test releases

  1. On test.10 or older, download the test.11 update. Extract it into the same folder, beside RPG_RT.ldb, and allow replacement of Player.exe and the 43 Map files.
  2. On test.11, download the test.12 update. Extract it into the same folder, beside RPG_RT.ldb, and allow replacement of the 45 Map files.
  3. Download the test.13 update. Extract it into the same folder, beside RPG_RT.ldb, and allow replacement of the 22 Map files.
  4. On test.13, v0.2.0, v0.3.0 or v0.3.1 (DC): download the v0.3.8 EN + MOD (DC) build, extract it to a new folder and copy your saves and config folders into it. Keep the new EasyRPG.ini.
  5. Copy your saves and config folders. Keep the new release's EasyRPG.ini so its current controls and label tables remain enabled. Saves from earlier tests load normally.
test.1–test.5 — optional historical engine upgrade

Skip this if you installed the test.6 or test.7 full game: the test.8 update above already replaces Player.exe.

  1. Close the game and back up the saves folder (or your existing custom save location).
  2. Download the test.6 Windows Player ZIP for Windows or Proton (the newest Player ZIP with all DLLs). Extract it separately.
  3. Copy Player.exe and all .dll files from that same ZIP into the folder containing your old Player.exe. Replace those files only. Keep saves, EasyRPG.ini and game data.
  4. Then apply the test.7 image update and the test.8 update from the section above; the test.8 Player.exe replaces the test.6 one and uses the same DLLs.

Native Linux now uses the same Player source as Windows; see Linux setup and tested limits. Existing patch-based installations can continue using their current game/save paths.
